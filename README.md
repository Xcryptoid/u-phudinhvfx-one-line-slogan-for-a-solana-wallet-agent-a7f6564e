## The slogan

> Your Solana wallet grew hands: it pays, swaps, and tidies up — while you keep the coins.

One line, 88 characters, 17 words — inside the kit's 20-word cap and the 1–140 character gate.

## Why this line

- It names the product outright: a Solana wallet, with an agent attached to it.
- "Grew hands" is a fresh image for a wallet agent — a wallet that can finally do things itself — instead of a stock crypto line about keys, moons, or bags.
- The promise is plain on one read: it pays, it swaps, it tidies up; you keep the coins.
- The contrast (the agent works / you keep the coins) gives it a rhythm that is easy to repeat.
- It stays honest: paying, swapping, and tidying are what a wallet agent does, and it promises nothing it cannot deliver.

## How it runs

`main.py` is a standard-library-only copier: it copies the pre-written slogan from `entry.txt` into `MAKEFUN_OUTPUT_DIR/entry.txt`, exactly as written, deterministically.
